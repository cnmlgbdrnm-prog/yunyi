# 服务器管理页 UI 重设计（卡片 + 操作分组）设计

> 日期：2026-08-26。现状：`src/views/Servers.tsx` 为单列堆叠：顶部工具区（批量测速/吞吐对测）平铺、每行 8 个按钮的「按钮墙」、信息无层级。重设计为卡片 + 主操作分组，行为与文案全部保留（含 P5 测速/BBR/对测/免密/通道态）。

## 1. 范围与验收

- 每台服务器一张卡片：左侧两行元信息（`host:port · user · 认证 · 系统`；`延迟 · 下载 · 上次测速`）+ 状态区（错误→链路摘要→BBR→免密结果，现有多行条件逻辑保留）；右侧主操作 `测速 / 连通测试 / 一键免密 / ⋯更多`
- 「更多」= 卡片内展开副操作行（BBR / 通道 / 部署（仅落地）/ 编辑 / 删除），再点收起；默认收起
- 工具区收敛为可折叠「工具」卡（默认展开），批量测速与吞吐对测控件、aria-label、结果文案全部保留
- 删除改用现有 `ConfirmButton`（两步确认）
- **验收**：既有测试全绿（仅“先点更多/确认删除”等选择器适配）；`npm test` + `npx tsc --noEmit` 通过；运行中 App 热更新后肉眼确认

## 2. 已确认决策（老板 2026-08-26）

| 项 | 决策 |
|---|---|
| 布局 | 卡片 + 操作分组（推荐项）；工具卡可折叠，默认展开 |
| 更多菜单 | 卡片内展开（非浮层），副操作行 `[BBR][通道][部署][编辑][删除]` |
| 视觉 | 沿用 Tailwind 4 暗色调：卡片 `bg-neutral-900/50 + border-neutral-800 rounded-lg`；类型徽章微型语义色（落地=蓝 `bg-blue-950 text-blue-300`、中转=天蓝 `bg-sky-950 text-sky-300`）；「已免密」绿标 `bg-emerald-950 text-emerald-300`；状态文案配色沿用（错误 `text-red-400` 等） |
| 约束 | 无 emoji（UI 规范）；中文文案；保留 aria-label（并发数/源服务器/目标服务器/对测秒数）与 role=alert；不加依赖、不动后端/IPC |
| 删除 | 换 `ConfirmButton`（label=删除 / confirmLabel=确认删除 / busyLabel=删除中…） |

## 3. 结构

```
┌ 服务器管理 ──────────────────────────── [+ 新建服务器] ┐
│ ▸ 工具（折叠头，默认展开）                             │
│   批量：并发[▾] [批量测速] [取消测速]（busy 时）        │
│   对测：源[▾] 目标[▾] 秒数[▾] [开始对测] [安装 iperf3()]│
│   最近对测 / 阶段 / 安装结果行                         │
└──────────────────────────────┴──────────────────────────┘
┌─ 名称 [类型徽章][已免密] ──────────────  [测速][连通测试][一键免密][更多 ▾] ┐
│  host:port · user · 密码 · Ubuntu 24.04                                  │
│  延迟 12ms · 下载 10.00 MB/s · 上次测速 …                                │
│  状态行（错误/链路摘要/BBR/免密结果，单条件多行）                         │
└─────────────────────────────────────────────────────────────────────────┘
  └─ [更多 展开] ── [BBR][通道][部署][编辑][删除] ──
  内嵌 ChannelPanel / DeployWizard 弹窗 / 编辑表单（内嵌卡片，结构不变）
```

数据流绑定：所有按钮 handler、busy 态、禁用条件、`job://progress` 订阅、liveResults、bbrAlgo/Msg、pwDone、throughputStage 等**逻辑一律不动**，仅重排渲染与新增 `moreOpen: Set<number>`、`toolsOpen: boolean` 两个局部 UI 状态。

## 4. 测试

- 适配（机械）：涉及 `编辑` / `删除` / `BBR` / `通道` 的用例先 `click('更多')`；删除用例改为点 `确认删除`；服务端删除与通道行内删除按区域定位不变
- 新增：更多展开/收起切换；工具卡折叠（展开时批量测速可用，折叠后不可见）；类型徽章与「已免密」徽章渲染
- 断言点保留：`getByText('密码')`（认证单独 span）、`'1.2.3.4:22'`、`/延迟 12ms/` 单行文本、`text-red-400` 类、`已免密（密钥认证）`、`免密成功：已切换密钥认证`
