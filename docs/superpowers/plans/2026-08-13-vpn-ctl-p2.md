# vpn-ctl P2 实施计划（服务器/凭据管理 + SSH 适配器 + 落地机一键部署）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一台全新 Ubuntu 落地机经工具完成 Xray（VLESS+Reality）或 SS（2022-blake3-aes-256-gcm）一键部署，节点自动写回节点页并可用。

**Architecture:** russh 纯 Rust SSH（生产客户端/测试 loopback 服务器/ed25519 密钥生成单库）；`ssh/` 适配器提供 async 连接/执行/真实超时；`servers/` 提供 CRUD/连通测试/免密与部署管道（探测→安装→配置→启动→写回，远端写文件走 base64 管道）；`jobs/` 提供串行队列 + 协作式取消 + 进度事件；命令层沿用 P1 `_cmd` 壳模式。

**Tech Stack:** Tauri 2 / React 19 / TS / Vite / Tailwind 4 / Vitest；Rust：russh、rusqlite、aes-gcm、reqwest、tokio。

## Global Constraints

- 规格事实源：`docs/superpowers/specs/2026-08-13-vpn-ctl-p2-design.md`（P2 设计，含全部决策记录）。
- SSH：russh 全套（生产客户端 + 测试服务器 + ed25519 生成），Windows 零 C/OpenSSL 依赖；禁止引入 ssh2/ssh-key。
- 部署协议固定最强档：Xray=VLESS+Reality（fallback 默认 `www.microsoft.com:443` 可改）、SS=`2022-blake3-aes-256-gcm`；身份材料全由工具生成（Xray=uuid v4、SS=32 字节随机密钥 base64 STANDARD），向导无密码输入项。
- 系统支持：仅 Debian/Ubuntu 家族（`/etc/os-release` 的 ID 含 `ubuntu`/`debian` 才继续，否则报「暂不支持的系统」）。
- 超时基线：SSH 连接 15s、探测命令 30s、安装 600s、配置/启动 60s、验证 30s。
- job 队列：单 worker 串行；status 集合 `queued|running|done|failed|cancelled`；取消协作式（步骤间检查 + `tokio::select!` 即时中断）；应用启动时把遗留 queued/running 标为 failed（错误文本「应用重启中断」）。
- IPC 契约（P1 教训）：invoke 参数 camelCase（Tauri 自动转 snake_case 只作用于参数），响应字段 snake_case；命令命名 `*_cmd`；前端只经 `src/api/` 访问。
- 事件：`job://progress`，payload `JobProgress { job_id, step, message, progress, error }`（字段 snake_case）。
- UI 一律不使用 emoji；错误文案中文、可理解；凭据材料（密码/私钥/SS key）不进日志、不进 error 文本、不进事件 payload。
- 生产源码无 TODO/FIXME/console.log/debugger；每个 `.rs`/`.ts(x)` 文件有中文模块说明（沿用 P1 风格）；单文件 ≤1000 行、组件 ≤300 行；TS 禁止 any。
- 每个新功能必须有测试；测试只 mock 外部依赖（IPC、网络、SSH 服务器），不 mock 被测模块自身。
- 部署为幂等：重复部署=覆盖配置+重启；免密公钥追加幂等。
- 提交风格沿用 P1：`feat(p2): …` / `fix(p2): …`，中文描述。

```rust
//! SSH 适配器测试：russh loopback 服务器真实验证连接/认证/执行/超时。
use super::{AuthMaterial, CommandOutput, SshError, SshSession};
use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use std::time::Duration;

/// 脚本化假 SSH 服务器：按 (包含匹配, exit, stdout, stderr) 顺序响应命令，
/// 记录全部命令；解析「echo '<b64>' | base64 -d > 路径」写入 files。
pub struct FakeSshServer {
    pub port: u16,
    password: Arc<Mutex<String>>,
    script: Arc<Mutex<VecDeque<(String, u32, String, String)>>>,
    pub recorded: Arc<Mutex<Vec<String>>>,
    pub files: Arc<Mutex<HashMap<String, Vec<u8>>>>,
    pub accepted_pubkeys: Arc<Mutex<Vec<String>>>,
    block: Arc<Mutex<Option<String>>>,
    handle: tokio::task::JoinHandle<()>,
}

impl FakeSshServer {
    pub async fn start() -> Self {
        // 先 bind 探随机端口再释放，run_on_address 自行绑定
        let listener = tokio::net::TcpListener::bind("127.0.0.1:0").await.unwrap();
        let port = listener.local_addr().unwrap().port();
        drop(listener);
        let state = Arc::new(SharedState {
            password: Mutex::new("secret".to_string()),
            script: Mutex::new(VecDeque::new()),
            recorded: Mutex::new(vec![]),
            files: Mutex::new(HashMap::new()),
            accepted_pubkeys: Mutex::new(vec![]),
            block: Mutex::new(None),
        });
        let server = FakeServer { state: state.clone() };
        let mut cfg = russh::server::Config::default();
        let key = russh::keys::key::KeyPair::generate_ed25519();
        cfg.keys.push(russh::keys::PrivateKeyWithHashAlg::new(Arc::new(key.secret().clone()), None));
        let cfg = Arc::new(cfg);
        let handle = tokio::spawn(async move {
            let _ = server.run_on_address(format!("127.0.0.1:{port}"), cfg).await;
        });
        // 等待端口可连（最多 2s）
        for _ in 0..20 {
            if tokio::net::TcpStream::connect(("127.0.0.1", port)).await.is_ok() { break; }
            tokio::time::sleep(std::time::Duration::from_millis(100)).await;
        }
        Self { port, password: state.password.clone(), script: state.script.clone(), recorded: state.recorded.clone(), files: state.files.clone(), accepted_pubkeys: state.accepted_pubkeys.clone(), block: state.block.clone(), handle }
    }
    pub fn set_password(&self, pw: &str) { *self.password.lock().unwrap() = pw.into(); }
    pub fn push_script(&self, contains: &str, exit: u32, stdout: &str, stderr: &str) {
        self.script.lock().unwrap().push_back((contains.into(), exit, stdout.into(), stderr.into()));
    }
    pub fn recorded(&self) -> Vec<String> { self.recorded.lock().unwrap().clone() }
    pub fn files(&self) -> HashMap<String, Vec<u8>> { self.files.lock().unwrap().clone() }
    pub fn accepted_pubkeys(&self) -> Vec<String> { self.accepted_pubkeys.lock().unwrap().clone() }
    /// 使匹配 contains 的命令挂起（测试用：取消/超时场景）。仅可有一个挂起点。
    pub fn block_on(&self, contains: &str) {
        *self.block.lock().unwrap() = Some(contains.to_string());
    }
    /// 终止服务器任务（释放挂起的命令）。
    pub fn release(&self) {
        self.handle.abort();
    }
}
```

```rust
//! SSH 适配器：russh 客户端连接、命令执行与真实超时。单命令时长由
//! tokio::time::timeout 约束，超时即中断通道；文件写入走 base64 管道
//! （由调用方 servers/deploy 提供白名单路径）。
//! 输入：主机/端口/用户/认证材料/命令；输出：CommandOutput 或 SshError。
//! 依赖：russh（async 客户端，纯 Rust）。

use std::time::Duration;
use thiserror::Error;

#[cfg(test)]
pub mod tests;

/// SSH 适配器错误：连接/认证/命令/超时/密钥格式。
#[derive(Debug, Error)]
pub enum SshError {
    #[error("无法连接 {host}:{port}: {reason}")]
    Connect { host: String, port: u16, reason: String },
    #[error("认证失败: {reason}")]
    Auth { reason: String },
    #[error("{step} 执行失败(exit={exit}): {stderr_tail}")]
    CommandFailed { step: String, exit: u32, stderr_tail: String },
    #[error("{step} 超时（{secs} 秒）")]
    Timeout { step: String, secs: u64 },
    #[error("密钥格式错误: {reason}")]
    KeyFormat { reason: String },
}

/// 命令输出。
#[derive(Debug, Clone, PartialEq)]
pub struct CommandOutput {
    pub stdout: String,
    pub stderr: String,
    pub exit_code: u32,
}

/// 认证材料：密码或 OpenSSH PEM 私钥文本。
#[derive(Debug, Clone)]
pub enum AuthMaterial {
    Password(String),
    PrivateKey(String),
}

struct ClientHandler;

#[async_trait::async_trait]
impl russh::client::Handler for ClientHandler {
    type Error = russh::Error;
    // 个人工具首次连接即信任主机密钥（TOFU 持久化列入 P3 backlog），不存 known_hosts
    async fn check_server_key(

        _server_public_key: &russh::keys::PublicKey,
    ) -> Result<bool, Self::Error> {
        Ok(true)
    }
}

/// 已连接的 SSH 会话。
pub struct SshSession {
    handle: russh::client::Handle<ClientHandler>,
}

impl SshSession {
    /// 建立连接并认证；conn_timeout 同时约束连接与认证两个阶段。
    pub async fn connect(
        host: &str,
        port: u16,
        user: &str,
        auth: &AuthMaterial,
        conn_timeout: Duration,
    ) -> Result<Self, SshError> {
        let config = russh::client::Config::default();
        let handle = tokio::time::timeout(
            conn_timeout,
            russh::client::connect(config, (host, port), ClientHandler),
        )
        .await
        .map_err(|_| SshError::Timeout { step: "连接".into(), secs: conn_timeout.as_secs() })?
        .map_err(|e| SshError::Connect { host: host.into(), port, reason: e.to_string() })?;

        let accepted = match auth {
            AuthMaterial::Password(pw) => tokio::time::timeout(
                conn_timeout,
                handle.authenticate_password(user, pw),
            )
            .await
            .map_err(|_| SshError::Timeout { step: "认证".into(), secs: conn_timeout.as_secs() })?
            .map_err(|e| SshError::Auth { reason: e.to_string() })?,
            AuthMaterial::PrivateKey(pem) => {
                let key = russh::keys::decode_secret_key(pem, None)
                    .map_err(|e| SshError::KeyFormat { reason: e.to_string() })?;
                tokio::time::timeout(
                    conn_timeout,
                    handle.authenticate_publickey(user, key),
                )
                .await
                .map_err(|_| SshError::Timeout { step: "认证".into(), secs: conn_timeout.as_secs() })?
                .map_err(|e| SshError::Auth { reason: e.to_string() })?
            }
        };
        if !accepted {
            return Err(SshError::Auth { reason: "服务端拒绝认证".into() });
        }
        Ok(Self { handle })
    }

    /// 执行命令；超时即中断。非零退出不报错，输出原样返回。
    pub async fn run(
        &mut self,
        step: &str,
        cmd: &str,
        timeout: Duration,
    ) -> Result<CommandOutput, SshError> {
        tokio::time::timeout(timeout, self.run_inner(cmd))
            .await
            .map_err(|_| SshError::Timeout { step: step.into(), secs: timeout.as_secs() })?
    }

    async fn run_inner(&mut self, cmd: &str) -> Result<CommandOutput, SshError> {
        let mut ch = self.handle.channel_open_session().await.map_err(|e| SshError::CommandFailed {
            step: "打开通道".into(), exit: 0, stderr_tail: e.to_string(),
        })?;
        ch.exec(true, cmd).await.map_err(|e| SshError::CommandFailed {
            step: "发送命令".into(), exit: 0, stderr_tail: e.to_string(),
        })?;
        let mut stdout = String::new();
        let mut stderr = String::new();
        let mut exit: Option<u32> = None;
        loop {
            match ch.wait().await {
                Some(russh::ChannelMsg::Data { data }) => {
                    stdout.push_str(&String::from_utf8_lossy(&data));
                }
                Some(russh::ChannelMsg::ExtendedData { data, .. }) => {
                    stderr.push_str(&String::from_utf8_lossy(&data));
                }
                Some(russh::ChannelMsg::ExitStatus { exit_status }) => {
                    exit = Some(exit_status);
                }
                Some(russh::ChannelMsg::Close) | None => break,
                _ => {}
            }
        }
        Ok(CommandOutput { stdout, stderr, exit_code: exit.unwrap_or(255) })
    }

    /// 执行命令并要求退出码为 0，否则 CommandFailed（带 stderr 末尾 500 字符）。
    pub async fn run_ok(
        &mut self,
        step: &str,
        cmd: &str,
        timeout: Duration,
    ) -> Result<CommandOutput, SshError> {
        let out = self.run(step, cmd, timeout).await?;
        if out.exit_code != 0 {
            let tail: String = out.stderr.chars().rev().take(500).collect::<Vec<_>>().into_iter().rev().collect();
            return Err(SshError::CommandFailed { step: step.into(), exit: out.exit_code, stderr_tail: tail });
        }
        Ok(out)
    }
}
```

```rust
struct FakeHandler { state: Arc<SharedState> }

#[async_trait::async_trait]
impl russh::server::Handler for FakeHandler {
    type Error = russh::Error;

    async fn auth_password(&mut self, _user: &str, password: &str) -> Result<russh::server::Auth, Self::Error> {
        if password == *self.state.password.lock().unwrap() {
            Ok(russh::server::Auth::Accept)
        } else {
            Ok(russh::server::Auth::Reject { proceed_with_methods: None, partial_success: false })
        }
    }

    async fn auth_publickey(&mut self, _user: &str, key: &russh::keys::PublicKey) -> Result<russh::server::Auth, Self::Error> {
        self.state.accepted_pubkeys.lock().unwrap().push(key.to_openssh().unwrap_or_default());
        Ok(russh::server::Auth::Accept)
    }

    async fn channel_open_session(
        &mut self, _channel: russh::ChannelId, _session: &mut russh::server::Session<Self>,
    ) -> Result<bool, Self::Error> {
        Ok(true)
    }

    async fn exec_request(
        &mut self, channel: russh::ChannelId, data: &[u8], session: &mut russh::server::Session<Self>,
    ) -> Result<(), Self::Error> {
        let cmd = String::from_utf8_lossy(data).to_string();
        self.state.recorded.lock().unwrap().push(cmd.clone());
        // 挂起点：匹配 block 的命令挂起，直到服务器任务被 release() 终止
        if let Some(contains) = self.state.block.lock().unwrap().clone() {
            if cmd.contains(&contains) {
                tokio::time::sleep(std::time::Duration::from_secs(3600)).await;
                session.exit_status_request(channel, 0);
                session.channel_success(channel);
                return Ok(());
            }
        }
        // 脚本优先（按序消费第一条匹配项）
        let mut script = self.state.script.lock().unwrap();
        if let Some(pos) = script.iter().position(|(c, ..)| cmd.contains(c.as_str())) {
            let (_, exit, stdout, stderr) = script.remove(pos).unwrap();
            drop(script);
            if !stdout.is_empty() { session.data(channel, stdout.as_bytes().to_vec().into()); }
            if !stderr.is_empty() { session.extended_data(channel, 1, stderr.as_bytes().to_vec().into()); }
            session.exit_status_request(channel, exit);
            session.channel_success(channel);
            return Ok(());
        }
        drop(script);
        // base64 写文件解析：echo '<b64>' | base64 -d > '<path>'
        if let Some((b64, path)) = parse_b64_write(&cmd) {
            let bytes = base64::Engine::decode(&base64::engine::general_purpose::STANDARD, b64).unwrap_or_default();
            self.state.files.lock().unwrap().insert(path, bytes);
        }
        session.exit_status_request(channel, 0);
        session.channel_success(channel);
        Ok(())
    }
}

/// 解析 `... echo '<b64>' | base64 -d > '<path>'`，返回 (b64, path)。
fn parse_b64_write(cmd: &str) -> Option<(String, String)> {
    let rest = cmd.split("| base64 -d > ").nth(1)?;
    let path = rest.trim().trim_matches('\'').to_string();
    let echo = cmd.split("echo '").nth(1)?;
    let b64 = echo.split('\'').next()?.to_string();
    Some((b64, path))
}
```

/// 校验输入并返回规整后的 Server 行（不含 id/created_at 的派生字段）。
fn validate_fields(name: &str, host: &str, port: i64, user: &str, auth_kind: &str, kind: &str) -> Result<(), ServersError> {
    if name.trim().is_empty() { return Err(ServersError::Validation("服务器名不能为空".into())); }
    if host.trim().is_empty() { return Err(ServersError::Validation("主机地址不能为空".into())); }
    if !(1..=65535).contains(&port) { return Err(ServersError::Validation("端口必须在 1-65535".into())); }
    if user.trim().is_empty() { return Err(ServersError::Validation("登录用户不能为空".into())); }
    if !matches!(auth_kind, "password" | "key") { return Err(ServersError::Validation("认证方式只能是 password 或 key".into())); }
    if !matches!(kind, "relay" | "landing") { return Err(ServersError::Validation("服务器类型只能是 relay 或 landing".into())); }
    Ok(())
}

/// seal 凭据并返回 (凭据行 id, base64 密文)。
fn seal_to_b64(creds: &CredentialService, material: &AuthMaterial) -> Result<(String, String), ServersError> {
    let plain = match material {
        AuthMaterial::Password(p) => p.as_bytes().to_vec(),
        AuthMaterial::PrivateKey(pem) => pem.as_bytes().to_vec(),
    };
    let blob = creds.seal(&plain).map_err(|e| ServersError::Crypto(e.to_string()))?;
    let b64 = base64::Engine::encode(&base64::engine::general_purpose::STANDARD, blob);
    let id = Uuid::new_v4().simple().to_string();
    Ok((id, b64))
}

/// 可注入的凭据加载：部署管道（无 AppState）复用同一逻辑。
pub fn load_auth_parts(db: &crate::db::Db, creds: &CredentialService, id: i64) -> Result<(AuthMaterial, Server), ServersError> {
    let conn = db.lock();
    let s = repos::servers::get(&conn, id).map_err(|e| ServersError::Db(e.to_string()))?.ok_or(ServersError::NotFound)?;
    let auth_ref = repos::servers::get_auth_ref(&conn, id).map_err(|e| ServersError::Db(e.to_string()))?.ok_or(ServersError::Validation("服务器缺少凭据".into()))?;
    let blob = repos::credentials::get_blob(&conn, &auth_ref).map_err(|e| ServersError::Db(e.to_string()))?.ok_or(ServersError::Validation("凭据不存在".into()))?;
    drop(conn);
    let bytes = base64::Engine::decode(&base64::engine::general_purpose::STANDARD, blob).map_err(|e| ServersError::Crypto(e.to_string()))?;
    let plain = creds.open(&bytes).map_err(|e| ServersError::Crypto(e.to_string()))?;
    let text = String::from_utf8_lossy(&plain).to_string();
    let auth = if s.auth_kind == "password" { AuthMaterial::Password(text) } else { AuthMaterial::PrivateKey(text) };
    Ok((auth, s))
}

pub fn create_server(state: &AppState, input: CreateServerInput) -> Result<Server, ServersError> {
    validate_fields(&input.name, &input.host, input.port, &input.user, &input.auth_kind, &input.kind)?;
    if input.credential.trim().is_empty() {
        return Err(ServersError::Validation("凭据不能为空".into()));
    }
    let material = match input.auth_kind.as_str() {
        "password" => AuthMaterial::Password(input.credential.clone()),
        _ => AuthMaterial::PrivateKey(input.credential.clone()),
    };
    let (cred_id, b64) = seal_to_b64(&state.creds, &material)?;
    let row = Server {
        id: 0,
        name: input.name.clone(), host: input.host.clone(), port: input.port, user: input.user.clone(),
        auth_kind: input.auth_kind.clone(), kind: input.kind.clone(), system: String::new(),
        notes: input.notes.clone(), created_at: chrono::Utc::now().to_rfc3339(),
    };
    {
        // 凭据与服务器行同事务写入，避免孤儿凭据
        let conn = state.db.lock();
        let tx = conn.transaction().map_err(|e| ServersError::Db(e.to_string()))?;
        repos::credentials::insert(&tx, &cred_id, &b64).map_err(|e| ServersError::Db(e.to_string()))?;
        repos::servers::insert(&tx, &row, &cred_id).map_err(|e| ServersError::Db(e.to_string()))?;
        tx.commit().map_err(|e| ServersError::Db(e.to_string()))?;
    }
    let id = state.db.lock().last_insert_rowid();
    Ok(Server { id, ..row })
}

    let conn = state.db.lock();
    let s = repos::servers::get(&conn, id).map_err(|e| ServersError::Db(e.to_string()))?.ok_or(ServersError::NotFound)?;
    if repos::servers::has_dependents(&conn, id).map_err(|e| ServersError::Db(e.to_string()))? {

    }

pub async fn test_connection(state: &AppState, id: i64) -> Result<ConnectionTest, ServersError> {
    let (auth, s) = load_auth(state, id)?;
    let mut sess = match SshSession::connect(&s.host, s.port as u16, &s.user, &auth, CONNECT_TIMEOUT).await {
        Ok(sess) => sess,
        Err(e) => {
            let message = match &e {
                SshError::Auth { .. } => "认证失败，请检查密码或私钥".to_string(),
                SshError::Connect { .. } => "无法连接主机".to_string(),
                SshError::Timeout { .. } => "连接超时".to_string(),
                other => other.to_string(),
            };
            return Ok(ConnectionTest { ok: false, system: String::new(), message });
        }
    };
    let out = sess.run("连通测试", "uname -s", PROBE_TIMEOUT).await.map_err(ServersError::from)?;
    if out.exit_code != 0 || out.stdout.trim().is_empty() {
        return Ok(ConnectionTest { ok: false, system: String::new(), message: "远端命令执行失败".into() });
    }
    let system = match sess.run("系统探测", "grep -m1 '^PRETTY_NAME=' /etc/os-release", PROBE_TIMEOUT).await {
        Ok(o) if o.exit_code == 0 => parse_pretty_name(&o.stdout),
        _ => String::new(),
    };
    if !system.is_empty() {
        repos::servers::set_system(&state.db.lock(), id, &system).map_err(|e| ServersError::Db(e.to_string()))?;
    }
    Ok(ConnectionTest { ok: true, system, message: String::new() })
}

/// 解析 `PRETTY_NAME="Ubuntu 22.04"` → `Ubuntu 22.04`。
fn parse_pretty_name(line: &str) -> String {
    line.trim()
        .split('=')
        .nth(1)
        .unwrap_or("")
        .trim()
        .trim_matches('"')
        .to_string()
}

```rust
/// 一键免密：生成 ed25519 → 用当前凭据登录下发公钥 → 切换 key 并删密码凭据。
pub async fn setup_passwordless(state: &AppState, id: i64) -> Result<(), ServersError> {
    let (auth, s) = load_auth(state, id)?;
    let keypair = russh::keys::key::KeyPair::generate_ed25519()
        .map_err(|e| ServersError::Ssh(SshError::KeyFormat { reason: e.to_string() }))?;
    let pub_line = keypair.public_key().to_openssh().map_err(|e| ServersError::Ssh(SshError::KeyFormat { reason: e.to_string() }))?;
    let pem = keypair.secret().to_openssh(russh::keys::ssh_key::LineEnding::LF)
        .map_err(|e| ServersError::Ssh(SshError::KeyFormat { reason: e.to_string() }))?;
    let mut sess = SshSession::connect(&s.host, s.port as u16, &s.user, &auth, CONNECT_TIMEOUT).await?;
    sess.run_ok("免密", "mkdir -p ~/.ssh && chmod 700 ~/.ssh", PROBE_TIMEOUT).await?;
    let append = format!(
        "grep -qF '{}' ~/.ssh/authorized_keys 2>/dev/null || echo '{}' >> ~/.ssh/authorized_keys; chmod 600 ~/.ssh/authorized_keys",
        pub_line, pub_line
    );
    sess.run_ok("免密", &append, PROBE_TIMEOUT).await?;
    // 验证公钥登录可用后（避免密钥未生效就切库导致失联）再切换
    let mut verify = SshSession::connect(&s.host, s.port as u16, &s.user, &AuthMaterial::PrivateKey(pem.clone()), CONNECT_TIMEOUT).await?;
    verify.run_ok("免密验证", "true", PROBE_TIMEOUT).await?;
    let (cred_id, b64) = seal_to_b64(&state.creds, &AuthMaterial::PrivateKey(pem))?;
    let conn = state.db.lock();
    let old_ref = repos::servers::get_auth_ref(&conn, id).map_err(|e| ServersError::Db(e.to_string()))?.unwrap_or_default();
    let tx = conn.transaction().map_err(|e| ServersError::Db(e.to_string()))?;
    repos::credentials::insert(&tx, &cred_id, &b64).map_err(|e| ServersError::Db(e.to_string()))?;
    repos::servers::set_auth_kind_ref(&tx, id, "key", &cred_id).map_err(|e| ServersError::Db(e.to_string()))?;
    if !old_ref.is_empty() {
        repos::credentials::delete(&tx, &old_ref).map_err(|e| ServersError::Db(e.to_string()))?;
    }
    tx.commit().map_err(|e| ServersError::Db(e.to_string()))?;
    Ok(())
}
```

```rust
    gate: Arc<Mutex<Option<tokio::sync::oneshot::Sender<()>>>>,
}

#[async_trait::async_trait]
impl DeployRunner for Recorder {
    async fn run(&self, req: DeployRequest, cancel: Arc<AtomicBool>, emit: EmitFn) -> Result<(), String> {
        let name = format!("{}:{}", req.kind, req.job_id);
        let concurrent = self.running.fetch_add(1, Ordering::SeqCst) + 1;
        self.max_concurrent.fetch_max(concurrent, Ordering::SeqCst);
        let n = self.events.lock().unwrap().len() + 1;
        self.events.lock().unwrap().push((name.clone(), n));
        emit(JobProgress { job_id: req.job_id, step: "测试".into(), message: name.clone(), progress: 50, error: None });
        if let Some(tx) = self.gate.lock().unwrap().take() {
            let _ = tx.send(());
        }
        // 等待放行或取消（最长 5s）
        for _ in 0..500 {
            if cancel.load(Ordering::SeqCst) {
                self.running.fetch_sub(1, Ordering::SeqCst);
                return Err("已取消".into());
            }
            tokio::time::sleep(Duration::from_millis(10)).await;
        }
        self.running.fetch_sub(1, Ordering::SeqCst);
        Ok(())
    }
}
```

```rust
//! job 队列：单 worker 串行执行部署任务。job 生命周期落 jobs 表
//! （queued→running→done/failed/cancelled），进度经 EmitFn 回传；
//! 取消为协作式：请求置位 AtomicBool，runner 步骤间检查。
//! 构造时把遗留 queued/running 行标为 failed（应用重启中断）。

use crate::db::repos;
use crate::domain::JobProgress;
use crate::db::Db;
use std::collections::HashMap;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex, RwLock};
use tokio::sync::mpsc;

#[cfg(test)]
pub mod tests;

pub type EmitFn = Arc<dyn Fn(JobProgress) + Send + Sync>;

/// 部署任务请求（jobs 行已由 start_deploy 建立）。
#[derive(Debug, Clone)]
pub struct DeployRequest {
    pub job_id: i64,
    pub server_id: i64,
    pub kind: String,
    pub port: u16,
    pub reality_dest: Option<String>,
}

/// 部署执行器：SSH 全序列 + 进度发射；错误文本决定 job 落 failed。
#[async_trait::async_trait]
pub trait DeployRunner: Send + Sync {
    async fn run(&self, req: DeployRequest, cancel: Arc<AtomicBool>, emit: EmitFn) -> Result<(), String>;
}

enum QueueMsg {
    Deploy(DeployRequest),
    Cancel { job_id: i64 },
}

pub struct JobQueue {
    tx: mpsc::UnboundedSender<QueueMsg>,
    cancels: Mutex<HashMap<i64, Arc<AtomicBool>>>,
    emit: Arc<RwLock<EmitFn>>,
}

impl JobQueue {
    /// 构造并启动 worker；同时执行启动恢复（遗留 queued/running → failed）。
    pub fn new(db: Arc<Db>, runner: Arc<dyn DeployRunner>) -> Self {
        if let Err(e) = repos::jobs::mark_interrupted(&db.lock()) {
            eprintln!("[vpn-ctl] 启动恢复失败: {e}");
        }
        let (tx, mut rx) = mpsc::unbounded_channel::<QueueMsg>();
        let cancels = Arc::new(Mutex::new(HashMap::<i64, Arc<AtomicBool>>::new()));
        let worker_cancels = cancels.clone();
        let worker_db = db.clone();
        let emit: Arc<RwLock<EmitFn>> = Arc::new(RwLock::new(Arc::new(|_| {})));
        let worker_emit = emit.clone();
        tokio::spawn(async move {
            while let Some(msg) = rx.recv().await {
                match msg {
                    QueueMsg::Cancel { job_id } => {
                        if let Some(flag) = worker_cancels.lock().unwrap().get(&job_id) {
                            flag.store(true, Ordering::SeqCst);
                        }
                    }
                    QueueMsg::Deploy(req) => {
                        let flag = Arc::new(AtomicBool::new(false));
                        worker_cancels.lock().unwrap().insert(req.job_id, flag.clone());
                        let _ = repos::jobs::update(&worker_db.lock(), req.job_id, "running", 5, None);
                        // 包装 emit：记录最后进度，供取消路径保留
                        let last = Arc::new(std::sync::atomic::AtomicI64::new(5));
                        let last2 = last.clone();
                        let base_emit = worker_emit.read().unwrap().clone();
                        let emit: EmitFn = Arc::new(move |mut p: JobProgress| {
                            if p.progress > last2.load(Ordering::SeqCst) {
                                last2.store(p.progress, Ordering::SeqCst);
                            }
                            p.error = None;
                            base_emit(p);
                        });
                        let result = runner.run(req.clone(), flag.clone(), emit).await;
                        let progress = last.load(Ordering::SeqCst);
                        let (status, error) = if flag.load(Ordering::SeqCst) {
                            ("cancelled", Some("已取消".to_string()))
                        } else {
                            match result {
                                Ok(()) => ("done", None),
                                Err(e) => ("failed", Some(e)),
                            }
                        };
                        let _ = repos::jobs::update(&worker_db.lock(), req.job_id, status, progress, error.as_deref());
                        // 失败/取消补发终态事件，UI 依赖 error 字段展示
                        if let Some(err_text) = error {
                            let base_emit = worker_emit.read().unwrap().clone();
                            base_emit(JobProgress {
                                job_id: req.job_id,
                                step: "结束".into(),
                                message: String::new(),
                                progress,
                                error: Some(err_text),
                            });
                        }
                        worker_cancels.lock().unwrap().remove(&req.job_id);
                    }
                }
            }
        });
        Self { tx, cancels, emit }
    }

    /// 设置生产事件发射器（main setup 中绑定 AppHandle）。
    pub fn set_emit(&self, emit: EmitFn) {
        *self.emit.write().unwrap() = emit;
    }

    /// 提交部署任务（jobs 行须已存在且为 queued）。
    pub fn submit(&self, req: DeployRequest) -> Result<(), String> {
        self.tx.send(QueueMsg::Deploy(req)).map_err(|e| e.to_string())
    }

    /// 请求取消；job 不存在或已结束时返回错误。
    pub fn cancel(&self, job_id: i64) -> Result<(), String> {
        let flag = self.cancels.lock().unwrap().get(&job_id).cloned().ok_or_else(|| "任务不存在或已结束".to_string())?;
        flag.store(true, Ordering::SeqCst);
        Ok(())
    }
}
```

取消的 status 落库为 `cancelled`，progress 保持 runner 最后发射值；worker 的 emit 包装保证 event payload 的 error 恒为 None（runner 发射的业务事件不带错误），终态错误由 worker 补发。

/// 解析 `xray x25519` 输出（"Private key: …" / "Public key: …"）。
pub fn parse_x25519_keys(stdout: &str) -> Result<(String, String), String> {
    let mut priv_k = None;
    let mut pub_k = None;
    for line in stdout.lines() {
        if let Some(v) = line.strip_prefix("Private key: ") {
            priv_k = Some(v.trim().to_string());
        }
        if let Some(v) = line.strip_prefix("Public key: ") {
            pub_k = Some(v.trim().to_string());
        }
    }
    match (priv_k, pub_k) {
        (Some(p), Some(q)) => Ok((p, q)),
        _ => Err("x25519 输出缺少密钥".into()),
    }
}

/// 远端写文件：mkdir -p 父目录 + echo b64 | base64 -d > 路径（路径为常量白名单）。
async fn write_remote_file(
    sess: &mut SshSession,
    cancel: &AtomicBool,
    step: &str,
    remote_path: &str,
    content: &str,
    timeout: Duration,
) -> Result<(), String> {
    let b64 = base64::Engine::encode(&base64::engine::general_purpose::STANDARD, content.as_bytes());
    let parent = remote_path.rsplit_once('/').map(|(p, _)| p).unwrap_or(".");
    let cmd = format!("mkdir -p '{}' && echo '{}' | base64 -d > '{}'", parent, b64, remote_path);
    run_cmd_ok(sess, cancel, step, &cmd, timeout).await?;
    Ok(())
}

/// 取消感知的单命令执行：取消标志置位即中断（不等命令超时）。
async fn run_cmd(
    sess: &mut SshSession,
    cancel: &AtomicBool,
    step: &str,
    cmd: &str,
    timeout: Duration,
) -> Result<crate::ssh::CommandOutput, String> {
    tokio::select! {
        out = sess.run(step, cmd, timeout) => out.map_err(|e| e.to_string()),
        _ = async {
            loop {
                if cancel.load(Ordering::SeqCst) { break; }
                tokio::time::sleep(std::time::Duration::from_millis(50)).await;
            }
        } => Err("已取消".into()),
    }
}

/// 取消感知 + 要求退出码为 0。
async fn run_cmd_ok(
    sess: &mut SshSession,
    cancel: &AtomicBool,
    step: &str,
    cmd: &str,
    timeout: Duration,
) -> Result<crate::ssh::CommandOutput, String> {
    tokio::select! {
        out = sess.run_ok(step, cmd, timeout) => out.map_err(|e| e.to_string()),
        _ = async {
            loop {
                if cancel.load(Ordering::SeqCst) { break; }
                tokio::time::sleep(std::time::Duration::from_millis(50)).await;
            }
        } => Err("已取消".into()),
    }
}

/// 部署主线。步骤：探测(10)→安装(40)→配置(60)→启动(85)→写回(100)。
async fn run_deploy(
    db: &Arc<crate::db::Db>,
    creds: &Arc<crate::crypto::CredentialService>,
    subs: &crate::subs::service::SubscriptionService,
    req: DeployRequest,
    cancel: &Arc<AtomicBool>,
    emit: &EmitFn,
) -> Result<(), String> {
    let server = {
        let conn = db.lock();
        repos::servers::get(&conn, req.server_id).map_err(|e| e.to_string())?.ok_or("服务器不存在")?
    };
    let emit_progress = |step: &str, message: &str, progress: i64| {
        emit(JobProgress { job_id: req.job_id, step: step.to_string(), message: message.to_string(), progress, error: None });
    };
    emit_progress("探测", "连接服务器", 5);
    let (auth, _) = crate::servers::load_auth_parts(db, creds, req.server_id).map_err(|e| e.to_string())?;
    let mut sess = SshSession::connect(&server.host, server.port as u16, &server.user, &auth, CONNECT_TIMEOUT).await.map_err(|e| e.to_string())?;

    // 1 探测（dry-run，不落配置）
    check_cancel(cancel)?;
    let arch = run_cmd_ok(&mut sess, cancel, "探测", "uname -m", PROBE_TIMEOUT).await?.stdout;
    let arch = arch.trim().to_string();
    let target = match arch.as_str() {
        "x86_64" => "x86_64-unknown-linux-gnu",
        "aarch64" => "aarch64-unknown-linux-gnu",
        other => return Err(format!("暂不支持的架构: {other}")),
    };
    check_cancel(cancel)?;
    let os_rel = run_cmd(&mut sess, cancel, "探测", "cat /etc/os-release", PROBE_TIMEOUT).await?.stdout;
    if !os_is_supported(&os_rel) {
        return Err(format!("暂不支持的系统（仅支持 Ubuntu/Debian 家族）: {}", os_rel.lines().find(|l| l.starts_with("ID=")).unwrap_or("未知")));
    }
    check_cancel(cancel)?;
    let bin = if req.kind == "xray" { "xray" } else { "ssserver" };
    let installed = run_cmd(&mut sess, cancel, "探测", &format!("command -v {bin}"), PROBE_TIMEOUT).await?.exit_code == 0;
    let port_busy = run_cmd(&mut sess, cancel, "探测", &format!("ss -tln 'sport = :{}' | grep -q .", req.port), PROBE_TIMEOUT).await?.exit_code == 0;
    if port_busy {
        return Err(format!("端口 {} 已被占用", req.port));
    }
    emit_progress("探测", if installed { "已检测到已装组件" } else { "探测完成" }, 20);
    check_cancel(cancel)?;

    // 2 安装
    if !installed {
        emit_progress("安装", "安装组件（可能耗时数分钟）", 30);
        match req.kind.as_str() {
            "xray" => {
                let cmd = format!("bash -c \"$(curl -L {})\" @ install", XRAY_INSTALL_URL);
                run_cmd_ok(&mut sess, cancel, "安装", &cmd, INSTALL_TIMEOUT).await?;
            }
            "ss" => {
                let (tag, asset) = latest_ss_asset(target).await?;
                let url = format!("https://github.com/shadowsocks/shadowsocks-rust/releases/download/{tag}/{asset}");
                let cmd = format!("curl -L -o /tmp/ss.tar.xz '{}' && tar -xJ -C /usr/local/bin -f /tmp/ss.tar.xz && rm /tmp/ss.tar.xz", url);
                run_cmd_ok(&mut sess, cancel, "安装", &cmd, INSTALL_TIMEOUT).await?;
            }
            other => return Err(format!("未知部署类型: {other}")),
        }
        check_cancel(cancel)?;
    }
    emit_progress("安装", "组件就绪", 45);
    check_cancel(cancel)?;

    // 3 配置
    emit_progress("配置", "生成配置", 55);
    let (params_json, _config_file, service) = match req.kind.as_str() {
        "xray" => {
            let uuid = Uuid::new_v4().to_string();
            let short_id: String = (0..8).map(|_| format!("{:x}", rand::random::<u8>() % 16)).collect();
            let reality_dest = req.reality_dest.clone().unwrap_or_else(|| "www.microsoft.com".into());
            let keys_out = run_cmd_ok(&mut sess, cancel, "配置", "xray x25519", CONFIG_TIMEOUT).await?.stdout;
            let (priv_k, pub_k) = parse_x25519_keys(&keys_out)?;
            let cfg = xray_config_json(req.port, &uuid, &short_id, &priv_k, &reality_dest);
            write_remote_file(&mut sess, cancel, "配置", XRAY_CONFIG_PATH, &cfg, CONFIG_TIMEOUT).await?;
            let params = serde_json::json!({
                "uuid": uuid, "security": "reality", "type": "tcp",
                "flow": "xtls-rprx-vision", "sni": reality_dest,
                "public-key": pub_k, "short-id": short_id, "fingerprint": "chrome"
            }).to_string();
            (params, cfg, "xray")
        }
        "ss" => {
            let key: [u8; 32] = rand::random();
            let pw = base64::Engine::encode(&base64::engine::general_purpose::STANDARD, key);
            let cfg = ss_config_json(req.port, &pw);
            write_remote_file(&mut sess, cancel, "配置", SS_CONFIG_PATH, &cfg, CONFIG_TIMEOUT).await?;
            write_remote_file(&mut sess, cancel, "配置", SS_UNIT_PATH, &ss_systemd_unit(), CONFIG_TIMEOUT).await?;
            let params = serde_json::json!({ "cipher": "2022-blake3-aes-256-gcm", "password": pw }).to_string();
            (params, cfg, "ssserver")
        }
        other => return Err(format!("未知部署类型: {other}")),
    };
    check_cancel(cancel)?;

    // 4 启动
    emit_progress("启动", "启动服务", 80);
    let start_cmd = match service {
        "xray" => "systemctl enable --now xray && systemctl restart xray".to_string(),
        _ => "systemctl daemon-reload && systemctl enable --now ssserver".to_string(),
    };
    run_cmd_ok(&mut sess, cancel, "启动", &start_cmd, CONFIG_TIMEOUT).await?;
    let active = run_cmd_ok(&mut sess, cancel, "启动", &format!("systemctl is-active {service}"), CONFIG_TIMEOUT).await?.stdout;
    if active.trim() != "active" {
        return Err(format!("服务未进入 active 状态: {}", active.trim()));
    }
    let listening = run_cmd(&mut sess, cancel, "启动", &format!("ss -tln 'sport = :{}' | grep -q .", req.port), CONFIG_TIMEOUT).await?.exit_code == 0;
    if !listening {
        return Err(format!("端口 {} 未监听", req.port));
    }
    check_cancel(cancel)?;

    // 5 写回
    emit_progress("写回", "写入节点与部署记录", 95);
    let node = Node {
        id: Uuid::new_v4().simple().to_string(),
        name: format!("{}-{}", server.name, if req.kind == "xray" { "xray" } else { "ss" }),
        source: "self-built".into(),
        protocol: if req.kind == "xray" { "vless".into() } else { "ss".into() },
        addr: server.host.clone(),
        port: req.port as i64,
        params_json,
        group_name: "自建".into(),
        sub_id: None,
        relay_rule_id: None,
        enabled: true,
        latency: None,
        bandwidth: None,
        last_checked_at: None,
    };
    let summary = serde_json::json!({ "kind": req.kind, "port": req.port, "protocol": node.protocol }).to_string();
    {
        let conn = db.lock();
        repos::nodes::upsert(&conn, &node).map_err(|e| e.to_string())?;
        repos::deploys::insert(&conn, req.server_id, &req.kind, &summary, "ok").map_err(|e| e.to_string())?;
    }
    subs.rebuild_config().await.map_err(|e| e.to_string())?;
    emit_progress("写回", "部署完成", 100);
    Ok(())
}

fn check_cancel(cancel: &AtomicBool) -> Result<(), String> {
    if cancel.load(Ordering::SeqCst) {
        Err("已取消".into())
    } else {
        Ok(())
    }
}

/// 查询 shadowsocks-rust 最新发布资产名（GitHub API，reqwest 15s 超时）。

    let j: serde_json::Value = resp.json().await.map_err(|e| format!("GitHub API 响应解析失败: {e}"))?;

```rust
pub fn start_deploy(state: Arc<AppState>, input: DeployInput) -> R<i64> {
    if !(1..=65535).contains(&input.port) {
        return Err(AppError::Message("端口必须在 1-65535".into()));
    }
    if !matches!(input.kind.as_str(), "xray" | "ss") {
        return Err(AppError::Message("部署类型只能是 xray 或 ss".into()));
    }
    {
        let conn = state.db.lock();
        let s = repos::servers::get(&conn, input.server_id).map_err(err)?.ok_or_else(|| AppError::Message("服务器不存在".into()))?;
        let _ = s;
    }
    let job_id = repos::jobs::insert(&state.db.lock(), "deploy", "queued").map_err(err)?;
    state.job_queue.submit(crate::jobs::DeployRequest {
        job_id,
        server_id: input.server_id,
        kind: input.kind,
        port: input.port,
        reality_dest: input.reality_dest,
    }).map_err(|e| {
        let _ = repos::jobs::update(&state.db.lock(), job_id, "failed", 0, Some(&e));
        AppError::Message(e)
    })?;
    Ok(job_id)
}

pub fn list_jobs(state: Arc<AppState>) -> R<Vec<Job>> {
    repos::jobs::list_recent(&state.db.lock()).map_err(err)
}

pub fn cancel_job(state: Arc<AppState>, job_id: i64) -> R<()> {
    state.job_queue.cancel(job_id).map_err(AppError::Message)
}
```

```tsx
// 部署向导：选协议/端口/fallback → 提交部署任务 → 订阅 job://progress 展示分步进度。
// 事件按 job_id 过滤；完成回调 onDone；取消经 cancelJob 通知后端。
import { useCallback, useEffect, useState } from 'react'
import { listen } from '@tauri-apps/api/event'
import { cancelJob, startDeploy } from '../api'
import type { JobProgress, Server } from '../api/types'

interface Props {
  server: Server
  onClose: () => void
  onDone: () => void
}

type Kind = 'xray' | 'ss'

function randomPort(): number {
  return 10000 + Math.floor(Math.random() * 50001)
}

export default function DeployWizard({ server, onClose, onDone }: Props) {
  const [kind, setKind] = useState<Kind>('xray')
  const [port, setPort] = useState(443)
  const [realityDest, setRealityDest] = useState('www.microsoft.com')
  const [jobId, setJobId] = useState<number | null>(null)
  const [progress, setProgress] = useState<JobProgress | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [starting, setStarting] = useState(false)

  // onDone 经 ref 调用，避免其引用变化导致事件订阅反复重建
  const onDoneRef = useRef(onDone)
  onDoneRef.current = onDone

  useEffect(() => {
    let disposed = false
    const unlisten = listen('job://progress', (e) => {
      const p = e.payload as JobProgress
      if (disposed || p.job_id !== jobId) return
      setProgress(p)
      if (p.error) {
        setError(p.error)
      }
      if (p.progress >= 100 && !p.error) {
        onDoneRef.current()
      }
    })
    return () => {
      disposed = true
      void unlisten.then((u) => u())
    }
  }, [jobId])

  const handleStart = useCallback(async () => {
    setError(null)
    setStarting(true)
    try {
      const id = await startDeploy({ serverId: server.id, kind, port, realityDest: kind === 'xray' ? realityDest : undefined })
      setJobId(id)
    } catch (e) {
      setError(String(e))
    } finally {
      setStarting(false)
    }
  }, [server.id, kind, port, realityDest])

  const handleCancel = async () => {
    if (jobId != null) {
      try {
        await cancelJob(jobId)
      } catch (e) {
        setError(String(e))
      }
    }
    onClose()
  }

  const running = jobId != null && progress?.error == null

  return (
    <div className="space-y-3 rounded border border-emerald-900 bg-neutral-900 p-4">
      <h3 className="text-lg font-semibold">部署落地机：{server.name}</h3>
      {error && (
        <p role="alert" className="rounded bg-red-950 px-3 py-2 text-sm text-red-300">
          {error}
        </p>
      )}
      <div className="flex gap-2">
        <label className="block w-32 text-sm">
          部署类型
          <select
            className="mt-1 w-full rounded border border-neutral-700 bg-neutral-900 px-2 py-1"
            value={kind}
            disabled={running}
            onChange={(e) => {
              const k = e.target.value as Kind
              setKind(k)
              setPort(k === 'xray' ? 443 : randomPort())
            }}
          >
            <option value="xray">Xray (Reality)</option>
            <option value="ss">SS (2022)</option>
          </select>
        </label>
        <label className="block w-28 text-sm">
          端口
          <input
            type="number"
            className="mt-1 w-full rounded border border-neutral-700 bg-neutral-900 px-2 py-1"
            value={port}
            disabled={running}
            onChange={(e) => setPort(Number(e.target.value))}
          />
        </label>
        {kind === 'xray' && (
          <label className="block flex-1 text-sm">
            Reality fallback 域名
            <input
              className="mt-1 w-full rounded border border-neutral-700 bg-neutral-900 px-2 py-1"
              value={realityDest}
              disabled={running}
              onChange={(e) => setRealityDest(e.target.value)}
            />
          </label>
        )}
      </div>

      {progress && (
        <div className="space-y-1 rounded border border-neutral-800 p-3">
          <p className="text-sm text-neutral-300">
            步骤：{progress.step} · {progress.message}
          </p>
          <div className="h-2 w-full overflow-hidden rounded bg-neutral-800">
            <div className="h-full bg-emerald-600 transition-all" style={{ width: `${Math.min(100, Math.max(0, progress.progress))}%` }} />
          </div>
        </div>
      )}

      <div className="flex gap-2">
        {!running ? (
          <button type="button" onClick={handleStart} disabled={starting} className="rounded bg-emerald-700 px-3 py-1.5 text-sm text-white hover:bg-emerald-600 disabled:opacity-50">
            {starting ? '提交中…' : '开始部署'}
          </button>
        ) : (
          <button type="button" onClick={handleCancel} className="rounded bg-red-800 px-3 py-1.5 text-sm text-white hover:bg-red-700">
            取消
          </button>
        )}
        {!running && (
          <button type="button" onClick={onClose} className="rounded bg-neutral-800 px-3 py-1.5 text-sm hover:bg-neutral-700">
            关闭
          </button>
        )}
      </div>
    </div>
  )
}
```

注意：`Math.random` 仅用于默认端口/未部署 UI 状态，与后端无契约（后端以提交值为准）。
